# DubFlow AI — Android MVP
A mobile UI prototype for a 50+ language video dubbing app.

Included:
- Video URL input
- 60+ language choices
- Source/target language selection
- Dubbing workflow UI
- Android WebView shell

Important:
This is an MVP UI, not a finished AI dubbing service. Real processing requires a backend for:
1. authorized video retrieval/upload
2. speech-to-text
3. translation
4. text-to-speech/voice generation
5. audio/video synchronization and rendering
6. file storage and download

Do not use it to bypass DRM, paywalls, or platform download restrictions.
